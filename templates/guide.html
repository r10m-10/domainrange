GUIDE

Math Suite is a symbolic math toolkit with six different tools, all using the same expression syntax. Everything is built from a hand-written tokenizer and parser to form ASTs. Simply type in an expression and pick a tool to get started.

Tools

FEATURES
  • AST Generator — See the raw parsed structure behind an expression.
  • AST Visualizer — View an expression as a tree diagram. Downloadable as SVG.
  • Domain Calculator — Find the domain of a function
  • Range Calculator — Find the range of a function.
  • Derivative Calculator — Find the derivative of a function.
  • Simplify — collapse a messy expression into its cleanest form
